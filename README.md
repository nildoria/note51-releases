# Note51 releases

Installers for **Note51**, an internal test app that records or imports calls, transcribes them on your own computer, and writes notes with OpenAI.

**[Download the latest version](https://github.com/nildoria/note51-releases/releases/latest)**

| Computer | File |
|---|---|
| Windows 10/11 (64-bit) | `Note51-Setup-<version>.exe` |
| Mac with Apple Silicon (M1–M4) | `Note51-<version>-arm64.dmg` |

Installation steps are on each release page. Installed copies of Note51 check this repository for updates: Windows updates itself, and the Mac app shows a download notice.

This repository holds installers only.
